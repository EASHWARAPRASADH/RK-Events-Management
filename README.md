# RK Events Website

A professional event management website built with React, Vite, and Tailwind CSS.

## Features

- 🎉 **Event Management**: Complete event planning and coordination
- 📸 **Gallery**: Comprehensive photo and video gallery
- �� **Services**: Wide range of event services
- 👥 **Partners**: Partner showcase and collaboration

## Technology Stack

- **Frontend**: React 18.3.1
- **Build Tool**: Vite 5.4.2
- **Styling**: Tailwind CSS 3.4.1
- **Routing**: React Router DOM 6.22.0
- **Icons**: Lucide React

## Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Start development server: `npm run dev`
4. Open browser: `http://localhost:5173`
