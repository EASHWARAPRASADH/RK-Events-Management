# 🎉 RK Events & Management

A modern, responsive website for RK Events & Management built with React, TypeScript, and Vite. This platform showcases our event management services, gallery, and allows potential clients to get in touch with us.

## 🚀 Features

### Frontend
- **Modern React 18** with TypeScript for type safety
- **Vite** for fast development and building
- **Responsive Design** with Tailwind CSS
- **Interactive UI** with smooth animations and transitions
- **Multi-page Navigation** (Home, About, Services, Gallery, Contact)
- **Image Galleries** with lightbox functionality
- **Mobile-first** responsive design

### Services Showcase
- **Event Planning** - Corporate events, weddings, and private parties
- **Venue Decoration** - Themed decorations and setups
- **Catering Services** - Custom menus for all occasions
- **Entertainment** - DJ, live music, and performances
- **Photography & Videography** - Professional event coverage

### Technical Features
- **Client-side Routing** with React Router
- **Optimized Performance** with code splitting
- **Modern CSS** with Tailwind CSS utility classes
- **Type Safety** with TypeScript
- **Fast Refresh** for better development experience

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Routing**: React Router DOM
- **Build Tool**: Vite
- **Linting**: ESLint
- **Code Formatting**: Prettier

## 🚀 Getting Started

### Prerequisites

- Node.js 14.18+ / 16+
- npm or yarn package manager

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/EashcodeX/RK-Events-And-Management.git
   cd RK-Events-And-Management
   ```

2. **Install dependencies**
   ```bash
   npm install
   # or
   yarn install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   # or
   yarn dev
   ```

4. **Open in your browser**
   The app will be running at [http://localhost:3000](http://localhost:3000)

### Building for Production

To create a production build:

```bash
npm run build
# or
yarn build
```

The build artifacts will be stored in the `dist/` directory.

1. Connect your repository
2. Set environment variables

## 🔧 Customization

2. Navigate to Services tab
3. Click "Add Service"

2. Go to Events tab
3. Add/edit/delete events as needed

1. Use admin portal media management
2. Upload new images or update existing ones
3. Images are automatically optimized and cached
